# Demo guide — make it look good

## Recording setup (5 min, do it once)

1. **Terminal theme** — iTerm2 (or Hyper): *Dracula*, *Snazzy*, or *One Dark*
   background, no window title bar chrome, **font size 15–16** so text is
   readable at reel scale.
2. **Window** — size the terminal roughly 100×30 so output doesn't wrap.
   Hide scrollbars.
3. **Record** — QuickTime (⌘⇧5 → Record Selected Portion) or OBS with the
   terminal window cropped. For an IG Reel you'll re-crop to 9:16 in CapCut:
   zoom the terminal to ~70% of frame width, add a headline top/bottom.
4. **Energy** — run `chmod +x demo.sh && ./demo.sh` and just let it play.
   It pauses ~3s between beats so you can cut precisely.

## The 9 beats (≈45s of footage)

| # | Beat | Why it lands |
|---|---|---|
| 1 | `subjects` | *"there's an entire catalogue of this"* — instant scale |
| 2 | `units Mathematics` | drill-down, shows you know the domain (P1, S1, M1…) |
| 3 | `--dry-run` | expectation set: exactly what we're about to grab |
| 4 | **download + progress bar** | the money shot — bar fills in real time |
| 5 | run again → "0 downloaded, N skipped" | proves resume/statefulness in 1 second |
| 6 | `stats` box | a clean summary panel, very screenshotable |
| 7 | `find` tree | the organised result |
| 8 | PDF opens | proof it's real papers, not links |
| 9 | **dashboard opens** | the product moment — interactive, click filters |

## The dashboard money shot

Open `papers/dashboard.html` fullscreen (⌘⇧F in Chrome). Click through, in
this order, while recording the screen:

1. KPI row — numbers up top
2. Coverage bars per subject
3. **Paper matrix** — switch subject via the dropdown, scroll the
   session×year grid (this is the "wow" visual)
4. Type a filter in the search box (`WMA11`) — table + counter react live
5. Scroll to "Awaiting Pearson publication" — honest limitation, earns trust

## Post-production tips

- Add a chyron over the dashboard: *"every IAL paper, one command"*
- Cut beat 4 tight to the bar filling; speed-ramp the middle of it
- For the reel's end card reuse your MOGGED-style thumbnail kit
- `open .` on the papers folder + Finder gallery view is a good B-roll shot
  (⌘4 → Gallery, makes PDFs look like cards)
